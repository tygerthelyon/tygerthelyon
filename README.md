# Carter Yott

I build tools for studying and playing quizbowl, combining a large Anki collection with question search and buzzer practice.

## Projects

**[QBCards & StockFisher](https://github.com/tygerthelyon/qbcards)** brings the work together:

- **StockFisher** indexes QBReader questions in SQLite to find recurring clues, compare answerlines, and check coverage against Anki notes.
- **Buzz Drill** streams tossups word by word and tracks buzz position and self-scored results.
- **Anki models** support a collection across physics, biology, fine arts, geography, history, philosophy, and more.

The November 2026 snapshot contained **11,921 notes**, **34,848 cards**, and a question mirror with **671,413 answerable units** from **716 sets**. The repository includes the code, note-type definitions, and selected samples; the full collection and mirror are local.
