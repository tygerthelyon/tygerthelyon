# Carter Yott

I build tools for studying and playing quizbowl, alongside an Anki collection covering fine arts, physics, biology, philosophy, and history, among others.

## Projects

### [QBCards & StockFisher](https://github.com/tygerthelyon/qbcards)

A high-performance study engine, clue extraction pipeline, and flashcard system for academic quizbowl:

- **StockFisher:** Indexes 670,000+ question units across 700+ sets in SQLite with FTS5 to identify recurring stock clues, exclusivity shares, and pyramid positioning.
- **Buzz Drill:** Real-time client-side tossup simulator with configurable reading speeds and keyboard interrupt buzzing.
- **Anki Knowledge Base:** 11,921 curated notes and 34,848 cards across fine arts, geography, sciences, and philosophy.

### [CEDT Health & Safety Website](https://github.com/tygerthelyon/cedt-safety) &middot; [Live Site](https://tygerthelyon.github.io/cedt-safety/)

A comprehensive departmental safety resources website developed for the Centre for Emerging Device Technologies (CEDT) and Engineering Physics at McMaster University, adapted from the previous website created by Graham Pearson.

- HTML5, CSS3, and JavaScript.
- Centralized runtime layout injector (`shared-layout.js`) and full-text search indexing.
   Python tools for link auditing (`check-links.py`) and automated search index regeneration (`build-search-index.py`).
